# Hire-To-Retire Power BI Model

Power BI report/model for the **Hire-to-Retire (H2R)** process.

## File

- `Hire-To-RetireModel.pbix` — Power BI Desktop report and data model.

## Open the report

1. Install [Power BI Desktop](https://powerbi.microsoft.com/desktop/).
2. Download or clone this repository.
3. Open `Hire-To-RetireModel.pbix` in Power BI Desktop.
4. If prompted, update the data-source credentials and refresh the report.

## Important security note

Before publishing this repository publicly, confirm that the PBIX file does not contain confidential company data, personal information, embedded credentials, or sensitive connection details. Use a private GitHub repository if the report is not intended for public access.

## Upload to GitHub

This repository is already initialized locally. Create an empty repository on GitHub, then run:

```bash
git remote add origin https://github.com/YOUR-USERNAME/Hire-To-RetireModel.git
git branch -M main
git push -u origin main
```

Replace `YOUR-USERNAME` with your GitHub username.
